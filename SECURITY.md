# Security Policy

## About This Repository

The ELEGOO Centauri Carbon Series repository is maintained by PandaWorks Studios.

It contains personally tested filament calibration profiles, slicer configurations, HueForge JSON data, and related documentation for the ELEGOO Centauri Carbon (ECC) and Centauri Carbon 2 Combo (ECC2C).

This repository does not distribute executable software or printer firmware.

## Supported Releases

Only the latest published release is actively maintained.

Older releases remain available for reference but may contain outdated calibration values, configurations, or documentation.

Users are encouraged to download the latest available release.

## Reporting Security Concerns

Although this repository primarily contains configuration files, concerns involving file integrity, unexpected configuration behavior, or potentially unsafe printer settings may be reported.

Please open a GitHub Issue for general configuration problems.

If you discover a genuine security vulnerability involving repository contents, please report it privately through GitHub's security reporting feature, if available.

## Important Safety Information

All configurations are provided as the results of testing performed on the maintainer's own equipment.

Printer hardware, firmware, filament formulations, environmental conditions, and individual machine tolerances may vary.

Users are responsible for reviewing settings before applying them to their printers.

**Do not apply configuration values that exceed the operating specifications of your printer, hotend, nozzle, or filament.**

## Disclaimer

The configurations provided in this repository are offered for informational and experimental use.

PandaWorks Studios does not guarantee identical results across different machines or operating environments.

Users assume responsibility for testing and applying these configurations to their own equipment.
