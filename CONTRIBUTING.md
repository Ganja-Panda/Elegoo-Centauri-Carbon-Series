# Contributing to the ELEGOO Centauri Carbon Series Repository

Thank you for your interest in this repository!

This project is maintained by PandaWorks Studios and serves as a public collection of personally tested filament calibration profiles for the ELEGOO Centauri Carbon (ECC) and Centauri Carbon 2 Combo (ECC2C).

## Calibration Contributions

**External filament calibration profiles and modifications to existing calibration values are not accepted.**

Every profile in this repository is based on testing performed on my own equipment, using my own calibration methods and printing conditions.

I cannot independently verify calibration results submitted by other users, and I want to maintain the integrity and consistency of the data published here.

You are welcome to download, reference, and adapt these configurations for your own equipment, subject to the repository's license.

## Issues and Feedback

Although calibration contributions are not accepted, feedback is welcome regarding:

- Broken links or missing files.
- Errors in documentation.
- Incorrect filenames or directory references.
- Problems accessing or using repository resources.

Please use GitHub Issues to report these problems.

## Pull Requests

Unsolicited pull requests modifying calibration profiles or adding externally calibrated filament profiles will not be accepted.

Documentation corrections may be considered at the maintainer's discretion.

## Project Philosophy

This repository exists to share the results of my own calibration work, not to collect calibration profiles from other sources.

**Test. Observe. Adjust. Repeat.**

Thank you for your understanding and interest in the project.
